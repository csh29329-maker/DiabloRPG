# DiabloRPG 0.4.0

Paper 1.21.1 / Java 21 / Gradle 9.9.2 기반 디아블로풍 RPG 플러그인.

## 빌드

```bat
:: Windows
gradlew.bat build
```

산출물: `build/libs/DiabloRPG-0.4.0.jar` → 서버 `plugins/` 폴더에 복사 (기존 DiabloRPG jar는 삭제).

> 이 ZIP의 코드는 **빌드/서버 실행 검증을 아직 하지 못했다.** (0.4.0은 소스 검토만 했고 컴파일도 못 해 봤다. 새 코드는 문법만 확인했다.) 처음 빌드할 때 컴파일 오류가 나면
> 오류 메시지를 그대로 전달해 수정한다.

## 업그레이드 주의

config.yml에 `resist:` 항목이 새로 생겼다. 기존 `plugins/DiabloRPG/config.yml`이 있어도
코드에 기본값(최대 75, 최소 -100)이 들어 있어 그대로 동작한다.
수치를 조정하려면 기존 config.yml을 삭제하고 서버를 다시 켜서 새 파일을 생성하거나,
아래 항목을 직접 추가한다.

```yaml
resist:
  max: 75
  min: -100
```

## 0.4.0 변경 사항: 룬 / 큐브 / 룬워드 [전부 미검증]

> **config.yml을 새로 만들어야 한다.** 기존 `plugins/DiabloRPG/config.yml`을 지우고 서버를 켜면 새 항목
> (`runes`, `cube`, `item-groups`, `runewords`)이 들어간 파일이 생성된다. 기존 파일에는 이 항목이 없어 룬워드가 동작하지 않는다.

### 룬 33종
- El ~ Zod (번호 1~33). 기반 아이템은 `AMETHYST_SHARD`(config `runes.item`), CustomModelData = 룬 번호.
- 지급: `/rpgrune give <플레이어> <룬|all> [개수]`, 목록: `/rpgrune list`, 레시피: `/rpgrune recipes`
- **리소스팩**: `resourcepack/DiabloRPG-Runes-ResourcePack.zip` (1.21.1 / pack_format 34). 룬마다 번호를 이진 점으로 표시한 임시 아이콘이다.
  없어도 동작한다(이름이 붙은 자수정 조각으로 보임). 서버에서 강제하려면 `server.properties`의
  `resource-pack`(URL)과 `resource-pack-sha1`을 쓴다. 로컬 테스트는 클라이언트 `resourcepacks` 폴더에 넣고 활성화한다.
  팩 파일은 `tools/make_pack.py`로 다시 만들 수 있다.

### 룬 드롭
- 적(Enemy) 또는 보스(위더, 엔더 드래곤, 워든, 엘더 가디언)를 **플레이어가 처치**하면 확률적으로 룬 1개가 드롭된다.
- 난이도 시스템이 없어서 `runes.difficulty`(normal/nightmare/hell)를 config에서 직접 정한다.
  난이도별 최대 룬: 노말 Ral(#8), 악몽 Ko(#18), 지옥 Lo(#28). 번호가 높을수록 `decay`만큼 드물다.
- 확률(일반 2%, 보스 25%, decay 0.8)은 모두 **임시값**이다. 드롭되면 콘솔에 `[룬 드롭]` 로그가 찍힌다.
- **아직 없음**: 별도 룬 파밍 장소와 전용 정예 몬스터, Lo 이상(Sur, Ber, Jah, Cham, Zod) 룬을 얻는 방법.

### 큐브
- `cube.block`(기본 `LODESTONE`)을 우클릭하면 큐브 창이 열린다. 웅크리고 클릭하면 열리지 않는다. 관리자는 `/rpgcube`로도 연다.
- 창 구성: 10번 칸 = 장비 1개, 12~17번 칸 = 룬(최대 6개), 22번 칸 = 제작 버튼(모루).
- 룬 순서는 상관없다. 장비는 **노말 등급**(PDC 등급이 normal이거나 일반 바닐라 아이템)이어야 한다.
  제작하면 룬이 1개씩 소모되고 장비가 룬워드 등급으로 바뀐다. 창을 닫으면 남은 아이템은 돌려받는다.
- 지원 장비 종류: sword, axe, mace, spear(삼지창), bow, crossbow, helmet, armor(가슴 갑옷), boots, shield.
  장갑/목걸이/반지/허리띠/단검/지팡이/마법봉은 대응하는 바닐라 아이템이 없어 아직 지원하지 않는다. 레깅스도 대상이 아니다.

### 룬워드 10종 (룬 조합은 디아블로 2 자료 두 곳에서 일치하는 것만 사용)
| 이름 | 룬 | 장비 | 현재 연결된 효과 |
|---|---|---|---|
| Steel | Tir El | 검/도끼/둔기 | 공격 속도, 공격력 |
| Malice | Ith El Eth | 근접 무기 | 공격력, 대상 방어력 감소 |
| Strength | Amn Tir | 근접 무기 | 공격력, 강타 |
| Stealth | Tal Eth | 가슴 갑옷 | 이동 속도, 독 저항 |
| Ancient's Pledge | Ral Ort Tal | 방패 | 방어력 증가, 모든 원소 저항 |
| Edge | Tir Tal Amn | 활/석궁 | 공격 속도, 악마 추가 피해 |
| Spirit | Tal Thul Ort Amn | 검 / 방패 | 최대 생명력 (방패는 모든 원소 저항도) |
| Insight | Ral Tir Tal Sol | 삼지창/활/석궁 | 공격력 |
| Fortitude | El Sol Dol Lo | 무기 / 가슴 갑옷 | 공격력 / 방어력 증가 |
| Grief | Eth Tir Lo Mal Ral | 검/도끼 | 공격 속도, 물리 피해 추가, 대상 방어력 감소 |

- **수치는 원작이 아니다.** 원작은 "+300% 공격력" 같은 값이라 이 서버 규모에 맞춰 임시값으로 정했다. 효과 종류도 이미 구현된 옵션으로
  가까운 것을 연결한 **근사치**다. 스킬/오라/발동/시전 속도/명중률 등은 시스템이 없어 `효과 없음`으로 로어에만 회색으로 표시된다.
- Enigma, Infinity 같은 Ber 이상 룬 조합은 해당 룬을 얻을 방법이 없어 아직 넣지 않았다.
- 모든 룬워드는 `config.yml`의 `runewords:` 섹션에서 추가/수정할 수 있다 (코드 수정 없이).
- 룬워드 아이템은 PDC 등급이 `runeword`이고 이름은 보라색이다. 전투 옵션은 기존 파이프라인이 그대로 읽는다.

### 같이 바뀐 것
- 보조 손에 든 **방패**의 방어/저항 옵션도 플레이어 방어 통계에 합산한다 (방패 룬워드용). 이전 버전은 갑옷 4칸만 읽었다.
- `/rpgitem give <플레이어> runeword ...`는 이제 "큐브에서 만든다"는 안내만 한다.

### 테스트 순서 (아무것도 실행해 보지 못함)
1. `/rpgrune give 내이름 all 5` 로 룬을 받고, `/rpgitem give 내이름 normal DIAMOND_SWORD` 로 노말 검을 받는다.
2. `/rpgcube`를 연다. 검을 왼쪽 칸, `Tir`와 `El`을 오른쪽 칸에 넣고 모루를 누른다 -> Steel(강철)이 되어야 한다.
3. 잘못된 조합, 룬워드 장비 재사용, 종류가 안 맞는 장비(예: Stealth를 검에)가 거절되는지 본다.
4. 창을 닫았을 때 아이템이 돌아오는지, 시프트 클릭/숫자키/드래그로 유리판 칸에 아이템이 들어가지 않는지 본다.
5. `LODESTONE`을 설치해 우클릭으로 열리는지 본다.
6. 만든 룬워드 무기로 `/rpgdummy` 샌드백을 쳐서 콘솔 로그의 옵션이 적용되는지 본다.
7. `runes.drop.chance`를 100으로 올려 좀비를 잡아 룬이 나오는지, `Ral`보다 높은 룬이 나오지 않는지 본다.

## 0.3.8 변경 사항

### 대상 버전을 Paper 1.21.1로 낮춤 [미검증]
- 이유: 모드와 플러그인을 함께 돌리는 하이브리드 서버(Arclight)로 나중에 옮길 수 있게 하기 위해서다.
  Arclight의 최신 빌드가 1.21.1이다. 지금은 Paper 1.21.1 서버에서 그대로 쓴다.
- `build.gradle`: `paper-api:1.21.1-R0.1-SNAPSHOT`.
- 1.21.3부터 바뀐 `Attribute` 상수 이름(`GENERIC_MAX_HEALTH` → `MAX_HEALTH` 등)은
  새 파일 `VersionCompat.java` 한 곳에서만 참조한다. 대상 버전을 바꿀 때는 이 파일만 고친다.
- 기능은 바꾸지 않았다. 서버 버전은 반드시 1.21.1이어야 한다. (1.21.4 서버에서는 `GENERIC_*` 상수가 없어 로드되지 않는다.)
- Arclight 이전 시 확인할 점: 이 플러그인이 Arclight에서 실제로 동작하는지는 확인하지 못했다.

## 0.3.7 변경 사항

### 샌드백 [미검증]
```
/rpgdummy spawn <normal|undead|demon> [방어%]   플레이어 앞 3칸에 소환
/rpgdummy clear                                 모든 샌드백 제거
```
- normal = 철 골렘, undead = 좀비(언데드 판정), demon = 블레이즈(악마 판정).
  악마/언데드 추가 피해 옵션 테스트용. 방어%를 생략하면 5%.
- AI/이동/소리를 끄고 체력 1024. 맞아도 죽지 않고 다음 틱에 체력이 가득 찬다.
- 이름표에 마지막 피해, 타격 횟수, 누적 피해가 표시된다. 피해는 방어/바닐라 방어구까지 반영된 최종값.
  (바닐라 방어구와 넉백은 0으로 맞춰 RPG 가상 방어%만 적용되게 했다.)
- 환경 피해(불, 용암 등)는 받지 않는다. 서버를 껐다 켜도 남아 있다.
- 테스트 예: `/rpgtest <플레이어> undead`로 받은 검으로 `undead` 샌드백을 때리면 +50%, `demon` 샌드백을 때리면 적용되지 않아야 한다.

## 0.3.6 변경 사항

### 유니크 아이템 시스템 [미검증]
- `config.yml`의 `uniques:` 섹션에 아이템을 적으면 `/rpgitem give <플레이어> unique <ID>`로 지급된다.
- 코드를 고치지 않고 설정만 추가해서 유니크를 늘릴 수 있다.
- 첫 유니크: `griswolds_edge` (그리스월드의 날).
  - 적용: 공격 속도 +10%, 공격력 +100~160%, 화염 피해(최소 10~12 / 최대 15~25, 타격마다 재롤), 대상 둔화 25
  - 효과 없음(로어에만 표시): 명중률 +100(공격은 항상 명중하는 설계), 힘 +12(능력치 미구현)
  - 미포함: 타격 시 4% 확률로 1레벨 피해 증폭 시전 (저주 시스템 없음)
- 범위 피해(`damage-ranges`): 생성 때 최소/최대 피해가 정해지고, 타격마다 그 사이에서 다시 굴린다.
  물리/화염/냉기/번개/독/비전 모두 지원. 화살에도 그대로 복사된다.
- 주의: "대상 둔화"는 지금 "N% 확률로 5초 둔화" 방식이라, 원작의 "항상 N% 감속"과 다르다.
- 기존 config.yml이 있으면 `uniques:` 항목이 없어 유니크가 나오지 않는다.
  기존 config.yml을 삭제하고 서버를 다시 켜서 새로 생성하거나, 위 항목을 직접 붙여넣는다.

## 0.3.5 변경 사항

- **버그 수정**: 음수 저항(예: `/rpgtest <플레이어> negres`)만 가진 갑옷을 입으면 피해자 핸들러가
  "방어 옵션 없음"으로 판단해 로그도 안 찍고 추가 피해도 적용하지 않던 문제를 고쳤다.
  원인은 `DefenseStats.hasAny()`가 값이 0보다 큰지만 검사한 것. 이제 0이 아니면 방어 통계로 본다.
  (0.3.4에서 `negres`가 동작하지 않은 것을 사용자 테스트에서 확인했다. 수정 후 재검증은 아직 못 했다.)

## 0.3.4 변경 사항

### 활/석궁 투사체 옵션 보존 [미검증]
- 활/석궁을 쏘는 순간 무기에 붙은 옵션을 화살 엔티티로 **통째로 복사**한다.
  (옵션 키 목록을 따로 관리하지 않아, 이후 추가되는 옵션도 자동으로 따라간다.)
- 화살이 명중하면 근접 공격과 같은 피해 파이프라인(공격력 증가, 물리/원소 피해, 원소 전환,
  치명타 1.5배, 강타 15%, 생명력 흡수, 방어력 감소, 악마/언데드, 둔화)으로 계산한다.
- 발사 후 무기를 바꾸거나 버려도 이미 날아간 화살의 옵션은 유지된다.
- 삼지창(던지는 창)은 이번 범위에 포함하지 않는다. (바닐라 동작)
- 플레이어 vs 플레이어: RPG 화살에 맞은 피해자는 공격 핸들러가 방어를 적용하므로
  피해자 핸들러는 건너뛴다. (RPG 무기 근접 공격과 같은 방식)

### 저항 상한 / 음수 저항 [미검증]
- 플레이어가 가진 물리 저항과 원소 저항은 최대 75%로 잘린다 (`resist.max`).
- 음수 저항을 허용한다. 저항 -50%이면 해당 피해를 1.5배 받는다. 하한은 -100% (`resist.min`).
- 대상 방어력 감소는 **양수** 방어/저항에만 적용한다. 음수 저항은 줄이지 않는다.
- 아직 아이템 옵션으로 음수 저항이 붙는 경로는 없다. (테스트 아이템 `negres`로만 확인 가능)

### 테스트 명령어 추가
```
/rpgtest <플레이어> bow       활 + 치명타 100%
/rpgtest <플레이어> crossbow  석궁 + 강타 100%
/rpgtest <플레이어> bowmix    활 + 치명타 100% + 화염 +10
/rpgtest <플레이어> overres   가슴 갑옷 화염 저항 120% (75%로 잘리는지)
/rpgtest <플레이어> negres    가슴 갑옷 화염 저항 -50% (화염 피해 1.5배)
```

### 이번 버전 테스트 방법 (아직 아무것도 실행해 보지 못함)
1. `bow`를 들고 좀비를 쏜다. 콘솔 로그에 `via=projectile ranged=true`와 `crit=true(... mult=1.5)`가
   나오는지 본다. 같은 화살을 맞은 좀비의 피해가 바닐라 활보다 큰지 본다.
2. `bowmix`로 쏜다. 로그에서 `physAfterCrit`는 1.5배, `elemental: 화염=10.0`은 배율 없이
   그대로인지 본다. (치명타는 물리에만)
3. `crossbow`로 쏜다. `crushing=true`와 대상 현재 체력의 15%가 추가되는지 본다.
4. 활을 쏜 직후 다른 아이템으로 바꿔 들어도 화살이 명중할 때 옵션이 적용되는지 본다.
5. 일반(바닐라) 활과 스켈레톤이 쏜 화살은 로그에 `via=projectile`이 찍히지 않아야 한다.
6. `overres` 갑옷을 입고 용암/불에 닿는다. 로그의 `elemRes`가 120이 아니라 75로 나오는지 본다.
7. `negres` 갑옷을 입고 같은 피해를 받는다. 로그의 피해가 저항 없는 상태의 1.5배인지 본다.
8. 석궁을 멀티샷(인챈트)으로 쏴서 옆으로 나가는 화살에도 옵션이 붙는지 본다. (불확실한 부분)

## 명령어

```
/rpgitem give <플레이어> <normal|magic|rare|unique|set|runeword> <아이템|random_weapon>
/rpgtest <플레이어> <종류>
```
- `normal` / `magic` / `rare`: 아이템 생성 동작.
- `unique`: `config.yml`의 `uniques:` ID로 지급 (0.3.6). `set`: **미구현** 응답만 반환. `runeword`: 큐브 안내만 반환.

## 구현 상태

### 구현 + 이전 버전에서 테스트됨 [적용]
공격력 증가 %, 물리 피해 추가, 화염/냉기/번개/독/비전 피해 추가, 원소 피해 전환, 생명력 흡수,
대상 방어력 감소, 공격 속도 증가, 최대 생명력, 이동 속도, 방어력 증가, 물리/원소 저항,
피해 감소, 악마/언데드 추가 피해, 대상 둔화.
(0.3.3 README/config에 [적용]으로 표시된 항목. 0.3.4에서는 이 항목들을 직접 다시 확인하지 못했다.)

### 로직 구현, 미검증 [로직]
치명타(근접 2배 / 활·석궁 1.5배, 물리에만), 강타(근접 25% / 활·석궁 15%, 현재 체력 비례, 물리에만)

### 미구현
세트 아이템, 룬 파밍 장소/정예 몬스터, Lo 이상 룬 획득, 룬워드 99종 중 나머지 89종, 능력치(힘/민첩/활력/기력), 시전 속도, 마법 저항, 생명력/마나 회복, 마나 증가, 처치 시 회복,
아이템 발견/골드/경험치, 회피, 저항 감소, 오라, 스킬 발동,
유니크/세트/룬워드 생성, 룬 드롭, 룬워드 제작, 난이도별 저항 페널티(악몽 -20% / 지옥 -40%),
보스 75% 초과 저항.

## 알려진 사항
- RPG 무기를 든 플레이어(또는 RPG 화살)에게 맞은 플레이어는 공격 핸들러에서만 방어가 적용된다.
  그런데 그 무기에 피해에 연결된 옵션이 하나도 없으면(공격 핸들러가 일찍 반환) 방어가 적용되지 않는다.
  0.3.3부터 있던 동작이며 이번에 바꾸지 않았다.
- 몹에는 저항이 없다(종류별 가상 방어%만 있음). 몹 저항이 생길 때 보스 예외(75% 초과)를 넣는다.
